This folder contains the scenario testing and sensitivity analysis workflows developed for the dissertation project.

The notebooks and scripts within this section were used to investigate how changes in NatureInsight® parameter settings influenced the quantity, distribution and performance of proposed Nature-based Solutions (NbS) interventions across the River Wansbeck catchment.

A central aim of the dissertation was to critically evaluate NatureInsight® as a catchment-scale decision-support tool, rather than solely assessing the suitability of NbS interventions themselves.

Scenario testing and sensitivity analysis were therefore undertaken to explore:

The responsiveness of outputs to user-defined settings
The stability and consistency of intervention recommendations
The influence of threshold selection and ranking criteria
Trade-offs between competing optimisation objectives
The transparency and reliability of model outputs

This formed a key part of the wider evaluation of uncertainty, usability and decision-support capability within the tool.

Parameters Investigated

Testing commonly varied:

Suitability Thresholds (e.g. SS30–SS80)
Rank selections (R1–R5)
Ordered By optimisation settings:
Default suitability
Storage
Carbon
Habitat

With particular focus on baseline comparisons.

Scenario outputs typically included:

Total intervention outputs

Intervention area (m²)
Catchment coverage (%)
Net carbon metrics
Net habitat metrics
Estimated implementation costs (£)
Dominant intervention type

Purpose of Analysis

The workflows within this folder were used to identify:

Threshold “tipping points”
Diminishing returns between scenarios
Highly sensitive model parameters
Stable versus unstable intervention recommendations
Trade-offs between storage, habitat, carbon and cost objectives

The analysis also supported wider dissertation discussion surrounding:

Decision-making uncertainty
Transparency limitations
Model assumptions
Multi-criteria analysis behaviour
The practical reliability of strategic NbS decision-support tools

Sensitivity analysis was considered particularly important due to the limited transparency surrounding internal weighting processes, assumptions and model behaviour within NatureInsight®.
