# Trade-Off Matrix and AHP Analysis

This folder contains the weighted trade-off matrix, Analytical Hierarchy Process (AHP) workflows and supporting literature descriptor frameworks developed for the dissertation project:

**“Evaluating Nature-Based Flood Management Opportunities in the River Wansbeck Using NatureInsight® as a Decision-Support Tool.”**

The workflows within this section were developed to extend the discussion beyond intervention suitability mapping alone, instead exploring how trade-offs, stakeholder priorities and implementation constraints may influence Nature-based Solution (NbS) decision-making in practice.

## Dissertation Context

A recurring theme identified throughout the dissertation literature review was that Nature-based Solutions frequently involve complex trade-offs between:

* Flood storage performance
* Biodiversity enhancement
* Carbon sequestration
* Cost and affordability
* Delivery feasibility
* Stakeholder acceptance
* Policy alignment
* Long-term risk and uncertainty


While NatureInsight® provides strategic optioneering and suitability mapping capabilities, the dissertation identified a gap between intervention identification and practical implementation-focused decision support.

This workflow was therefore developed to explore how NatureInsight® outputs could be extended into a more transparent trade-off evaluation framework.

## BRITE-NI Concept

The matrix forms part of a conceptual framework proposed within this study:

### **BRITE-NI**

**Budget-Responsive Intervention and Trade-off Evaluator — NatureInsight**

BRITE-NI is proposed as a potential future extension to NatureInsight®, intended to support implementation-stage decision-making by integrating:

* Stakeholder priorities
* Budget constraints
* Trade-off evaluation
* Weighted intervention comparison
* Literature-informed benchmarking
* Transparent ranking systems

Rather than solely displaying spatial suitability outputs, the concept explores how decision-support tools could better support the complex prioritisation processes required during real-world NbS implementation. It begins with a cost constraint, ahead of NbS suggestions, as this was revealed as a huge dictator in implementation across NbS uptake. Primarily, it seeks to translate NatureInsight recomendations into implementation support, to enhance usability of NatureInsight- particulalry for those who trade-off evaluation is new to.

## Purpose of the Matrix

The matrix was developed to compare and outline a gap between:

* **NatureInsight-derived intervention performance**
  against
* **Literature-informed scored expectations**

This enables comparison between modelled tool outputs and wider published evidence surrounding intervention behaviour and effectiveness.

The analysis helps identify:

* Strongly supported intervention relationships
* Potential conflicts and trade-offs
* Areas of uncertainty or weak evidence
* Gaps between model outputs and published literature
* Criteria where evidence remains highly context-dependent

The workflow also highlights where available evidence may remain limited, inconsistent or “fuzzy”, helping demonstrate uncertainty within both the literature base and the tool itself.

## Ranking and Descriptor Frameworks

This folder contains supporting documentation and descriptor frameworks used to standardise scoring and reduce subjectivity within the analysis.

Rather than using vague classifications such as “good” or “poor”, numerical ranking scales (1–5) were developed using literature-informed descriptors to improve transparency and consistency.

These descriptors provide justification for what constitutes:

* Very weak performance
* Weak performance
* Moderate performance
* Strong performance
* Very strong performance

across each assessment category.

Supporting files within this folder include:

* Literature descriptor frameworks
* NatureInsight scoring guidance
* Pre-defined literature ranking logic
* Intervention scoring criteria
* AHP pairwise comparison workflows
* Weighting justification tables

## Analytical Hierarchy Process (AHP)

The notebook incorporates AHP and pairwise comparison methods to generate weighted stakeholder priorities across multiple criteria.

This allows users to explore how differing priorities influence intervention rankings and trade-off outcomes. The weighting reflects personalised preferences so an ultimate trade-offs can be determined

Criteria assessed include:

* Storage
* Habitat
* Carbon
* Cost
* Cost-effectiveness
* Time to effectiveness
* Durability
* Stakeholder risk
* Policy alignment
* Disservices risk

The workflow generates weighted outputs and comparative scoring tables to support more transparent multi-criteria evaluation.

## Matrix Outputs

Outputs generated include:

* Weighted comparison tables
* NatureInsight vs literature scoring matrices
* Gap analysis tables
* Ranked intervention performance summaries
* Stakeholder-specific weighting outputs
* Colour-coded trade-off visualisations

The matrix visualisations use a simplified colour convention inspired by Italian Flag Assessment Matrix approaches identified within the literature and adapted for use within this dissertation workflow.

Within the outputs:

* Green generally reflects stronger relationships or alignment
* Red reflects weaker relationships, conflicts or limitations
* Intermediate colours represent mixed or uncertain outcomes

This approach was intended to improve interpretability and communication of complex trade-off relationships.

## Dissertation Relevance

This section represents a key extension of the dissertation beyond standard spatial analysis by exploring:

* Decision-support transparency
* Multi-criteria uncertainty
* Stakeholder-driven prioritisation
* Implementation feasibility
* Practical flood management trade-offs
* The future development of NbS decision-support tools

The workflows developed here demonstrate how strategic suitability tools such as NatureInsight® may be further refined to better support implementation-stage decision-making and stakeholder communication.


## Notes

The scoring systems and descriptor frameworks developed within this folder are exploratory and were created specifically for this dissertation research.
The intention is not to present definitive universal intervention rankings, but rather to demonstrate a moreadaptable framework for incorporating trade-offs and stakeholder priorities into NbS decision-support workflows.
