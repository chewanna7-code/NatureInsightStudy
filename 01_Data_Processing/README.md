# Data Processing

This folder contains the primary data preparation, cleaning and formatting workflows used throughout the dissertation project:

“Evaluating Nature-Based Flood Management Opportunities in the River Wansbeck Using NatureInsight® as a Decision-Support Tool.”

The notebooks and scripts within this section were used to process, structure and standardise outputs exported from NatureInsight® and associated datasets prior to analysis.

Key Functions
Importing and organising NatureInsight® scenario outputs
Parsing scenario naming conventions (e.g. Rank, Threshold and Ordered By settings)
Cleaning and restructuring exported Excel datasets
Combining scenario outputs into master summary tables
Standardising intervention metrics across scenarios
Preparing datasets for sensitivity analysis, hydrograph comparison and weighted trade-off evaluation
Automating repetitive processing tasks using Python
Typical Metrics Processed

Processed datasets commonly included:

Total storage (m³)
Intervention area (m²)
Catchment coverage (%)
Estimated costs (£)
Net carbon metrics
Net habitat metrics
Dominant intervention type
Intervention-specific outputs

Outputs generated here were subsequently used in:

Scenario testing
Sensitivity analysis
Hydrograph analysis
Subcatchment evaluation
Spatial assessment
AHP and weighted trade-off analysis

Notes:
This information was derived primarily from the built-in SCALGO download, available in the NatureInsight tool
